# Security

Offline lookup, rendering, validation and installation run on stdlib Python with no secrets or external calls. The **optional** external indexer requires an explicit flag, checks `robots.txt`, respects a per-request pause, and fetches titles/links only. Review the code and site conditions before network use. Do not provide brokerage credentials, wallet keys, bank passwords, API secrets, proprietary statements or private customer data to public issue reports. Report vulnerabilities privately via standard GitHub repository security channels rather than publishing exploits.
