# Evidence standard and answer template

## Label every claim

1. **Observed / reported:** primary data or a user-provided dataset with timestamps and units.
2. **Calculated:** deterministic transformation with a formula, source and reproducible parameters.
3. **Interpretation / hypothesis:** causal explanation, chart-pattern classification or forecast.
4. **Unknown:** missing exposure, release vintage, incomplete price history or restricted source access.

Seek primary statistical agencies (BEA, BLS, FRED metadata, Eurostat, IMF, national central banks), filings/issuer reports, contract specifications and exchange rulebooks. Investopedia is a helpful educational secondary source, not data-of-record for new releases. Cite exact URLs and observed dates when obtained; do not treat the alphabetical index as proof a full article was read.

## Output outline (adapt to question)

**Question and frame:** instrument, geography, horizon, benchmark, timestamp.

**Finding:** what is visible or computed, with confidence wording.

**Mechanism:** short explanation and numbers/formula as appropriate.

**Alternative and failure test:** what contradicts it, what could make analysis wrong.

**Source/vintage:** primary source first and reproducible inputs/limitations.

## Data hygiene

No filling unobserved values with plausible-looking numbers. No generic 'statistically proven' claims. If data are inaccessible, show the required inputs and refrain from numeric conclusions. If user requests investment guidance, distinguish educational research from individualized recommendations.
